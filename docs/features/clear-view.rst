Clearing the view
=================

**Clear view…** in the library bar removes the photos in view from
Picturesque without deleting any file. With filters, only the photos
matching them are removed (a stack counts with all its photos); without,
every photo is.

- Their picks, ratings, scores and species in Picturesque are forgotten;
  what was already written to their sidecars stays.
- They do not come back while their files are unchanged; new photos in the
  folder appear as usual.
- In the library, the copies stay in the library folder. Importing the same
  files again would copy them again.

When a folder is culled in place (a memory card), photos whose RAW and
image files are gone, for example after the card was formatted, leave the
view by themselves each time the folder is checked. A card that is not
inserted keeps its photos in view.
